## Suggested usage

- Use `fig_psnr_vs_noise_variance.png` and `fig_mse_vs_noise_variance.png` for the quantitative results section.
- Use `fig_comp_image1_sigma05.png` to discuss the low-noise case where Gaussian filtering remains very strong.
- Use `fig_comp_image1_sigma10.png`, `fig_comp_image1_sigma15.png`, and `fig_comp_image1_sigma25.png` to show how sparse coding improves as noise increases.
- Use `fig_comp_image2_sigma25.png` and `fig_comp_image3_sigma25.png` as extra qualitative examples.
- Use `fig_dictionary_image1_sigma25.png` to illustrate the learned atoms.
